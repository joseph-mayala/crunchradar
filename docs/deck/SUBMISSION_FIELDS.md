**Project summary** (the form needs 50+ characters; this is about 560):

> Every lecturer sets deadlines for one module, so nobody sees the whole cohort's week and students hit crunch weeks with no warning. CrunchRadar reads a cohort's deadlines and assignment briefs, adds up the real hours per week against a limit built on MQA's 40-hours-per-credit rule, and proposes deadline moves the rules allow. A Gemini agent plans each Monday run through tool calls, and a named person approves every move through a single-use link before anyone is told. It is a working prototype on a labelled sample cohort, with 125 automated tests and MCP tools, built to move into Gemini Enterprise.
